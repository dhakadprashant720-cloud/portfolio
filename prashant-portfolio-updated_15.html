Real-Time Fraud Detection System with Explainable AI

Built an end-to-end fraud detection pipeline on the IEEE-CIS Credit Card dataset — 590,000 real-world financial transactions with 433 features and a severe 3.5% fraud rate.

Data & Preprocessing: Merged train_transaction.csv and train_identity.csv on TransactionID. Handled missing values (dropped columns >50% null, imputed median/mode), label-encoded high-cardinality categoricals, and engineered 3 custom features: AmtToMeanRatio, HourOfDay, and DeviceRisk.

Imbalance Handling: Applied SMOTE on training data only with stratified 80/20 split and RobustScaler — corrected class imbalance without data leakage.

Models Trained: Compared LightGBM, XGBoost, and Isolation Forest — evaluated on Accuracy, Precision, Recall, F1, ROC-AUC, and PR-AUC. Best model tuned with Optuna for optimal threshold via F1-Score curve.

Explainable AI (SHAP): Generated Global SHAP Summary Plot (top 20 features), Waterfall Plots for confirmed fraud, borderline, and legitimate transactions — and translated every prediction into plain-English business reasoning for compliance teams.

Risk Segmentation: Classified all transactions into 3 tiers — 🔴 Critical (≥0.75), 🟡 Suspicious (0.40–0.74), 🟢 Clear (<0.40) — with per-tier analysis of average transaction amount, device type, and hour-of-day fraud patterns.

Live Dashboard: Deployed a multi-page Streamlit app on Streamlit Community Cloud — featuring live transaction search, real-time risk scoring by TransactionID, interactive Plotly charts, and an on-demand SHAP explainer page for any transaction.

Python NLP TF-IDF Scikit-learn NLTK Chrome Extension JavaScript

Fake Review Detection — NLP & ML with Live Chrome Extension

Built a complete end-to-end NLP pipeline to automatically classify e-commerce product reviews as Fake or Real — combating the growing problem of fake reviews that mislead millions of online shoppers daily.

Text Preprocessing Pipeline: Raw review text was cleaned through lowercasing, punctuation removal, stopword filtering, and lemmatization using NLTK — converting messy user text into a standardized, model-ready format.

Feature Engineering: Applied TF-IDF Vectorization to convert processed text into numerical feature vectors — capturing word importance across the corpus while reducing noise from common, low-value terms.

Model Training & Results: Trained a classification model using Scikit-learn achieving 88% accuracy — evaluated using Precision, Recall, and F1-Score to ensure reliable fake review flagging with minimal false positives.

Chrome Extension Deployment: Packaged the entire trained model + pipeline into a live Chrome Extension using JavaScript — users can browse any Amazon, Flipkart, or e-commerce product page and get instant real-time fake review detection with a single click, directly in their browser.
